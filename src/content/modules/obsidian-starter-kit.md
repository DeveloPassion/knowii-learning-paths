## Do this first

1. Install Obsidian if you haven't. Open the kit as a **new vault**. Do not copy its folders into an existing one; merge later, once you understand the structure.
2. Read the user guide's home page and pick your starting point. There's a section literally called "Choose Your Starting Point". Trust it.
3. Create today's daily note with the template. Write three lines in it. Done. You've used the system.

That's day one. Resist the urge to configure anything. The defaults are the defaults because they work.

## Then

- Days 2 to 7: only daily notes. Capture whatever crosses your mind. Let the structure sit there unused. You're building the habit, not the cathedral.
- Week 2: create your first permanent notes from what accumulated in the daily notes. Use the templates. Watch them file themselves.
- Week 2 or 3: try the AI assistant. The "Getting started with AI in OSK" tutorial is a first-run tour. It only makes sense once you have some notes for it to work with.
- Any time you don't know why something is set up the way it is: look it up in the user guide before changing it. There's a reason, and it's usually written down.

## Skip it if

You've already built your own vault that you love and that scales. Then read the user guide anyway for the ideas, and steal what you like.
